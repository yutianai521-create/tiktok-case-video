# Platform copy and claims

Use this reference only when the task includes a TikTok/YouTube caption, on-screen copy, or moderation concern.

## Write for reach without inventing rules

No single word can be assumed to cause suppression across all accounts and contexts. Do not claim that terms such as “AI” or “agent” are universally banned or guaranteed to reduce reach. If the user wants conservative copy, emphasize the human-readable story and use the product term only where it adds meaning.

## Safer default pattern

1. Lead with the concrete event.
2. Add one line of context.
3. End with a natural question or invitation when appropriate.
4. Use a small, relevant hashtag set; include required tags exactly.

Avoid:

- guaranteed earnings, guaranteed views, or exaggerated outcomes;
- unsupported “first ever,” “fully autonomous,” or “made without humans” claims;
- sensational language that does not match the video;
- unnecessary personal or transaction identifiers;
- copying a long X post into the TikTok caption.

## Length guidance

- Short captions often work well when the video explains itself.
- A longer caption is useful only when it adds context not already visible or spoken.
- If a strict character limit is given, count spaces, punctuation, and hashtags.
- Keep hashtags relevant; more tags do not automatically improve distribution.
