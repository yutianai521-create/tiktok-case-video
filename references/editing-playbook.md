# Editing playbook

Use this reference when planning or revising the actual video.

## Choose an edit mode

### Source-led montage

Best when there are several strong original clips. Open on movement, introduce the subject through action, and use short labels rather than explanatory cards. Keep each excerpt long enough to register but short enough to feel re-authored.

### Narrated case story

Best when the narrative matters more than the raw footage. Alternate between source clips, factual proof, and restrained kinetic type. Build the visual order around the voiceover rather than laying narration over a prebuilt montage.

### One-asset story

Best when only one avatar and one finished work are available. Use each once. Let typography, layout changes, detail crops, and a clean result reveal carry the remaining beats. Do not manufacture multiple “shots” by repeatedly zooming the same still.

### Product or feature explainer

Best when showing a mechanism rather than a character story. Start with the user benefit, demonstrate one clear sequence, then end on the changed state. Avoid stacking feature lists.

### Audio-led event cutdown

Best when an AMA, interview, podcast, or livestream has no usable live video. Use the original audio as the spine, establish the speaker with a portrait and role, animate a real waveform, and reveal supporting screenshots only when they advance the quote. Fill only the necessary setup with narration.

## Useful pacing patterns

### 15-second case

| Time | Purpose | Typical visual |
|---|---|---|
| 0–2s | Hook | Movement or one bold line |
| 2–5s | Before | Identity or first state |
| 5–8s | Change | Request, decision, or transaction |
| 8–12s | Result | Original work plays continuously |
| 12–15s | Outcome | Price, delivery, or return behavior |

### 20–25-second montage

Use 1–3 second excerpts, but vary the rhythm. A uniform two-second cut cadence quickly feels mechanical. Save one 3–5 second hold for the strongest result.

## Mixed aspect ratios

Choose one system and keep it consistent:

- **Full bleed crop:** suitable when subjects remain readable after 9:16 cropping.
- **Editorial frame:** place the complete source inside a consistent portrait canvas with intentional margins, labels, and background color.
- **Split field:** use copy in one region and the source in another; useful for square or 4:3 assets.
- **Detail sequence:** alternate a full view with true crops of different details. Do not use near-identical crops as fake variety.

Never stretch footage. Black space is acceptable only when it is an intentional part of the design, not an unhandled aspect-ratio mismatch.

For a landscape source converted to 9:16, preserving the full frame inside a black portrait canvas is a valid editorial system. Use the upper black region for a short headline and the lower region for subtitles. Manually split long subtitles into balanced two-line phrases.

## Event-video house style

When the user asks to match the established Pip email-video style:

- use a near-black background such as `#101214`;
- set body type in white and one active or decisive phrase in lime `#D7FF3F`;
- keep source labels in cool gray;
- change crop, evidence, or emphasis every 1–2 seconds;
- show one reading target per shot;
- use screenshots, profile cards, and public logs instead of generic robot or hologram footage;
- add a small black backing shape when captions sit over footage;
- keep text above platform controls and away from faces and source lines.

## “No AI feel” translation

This normally means editorial restraint, not the absence of digital tools:

- borrow color and texture from the supplied world;
- favor real source media over generated filler;
- use one or two typefaces with a clear hierarchy;
- keep motion physical and motivated;
- avoid floating glass panels, random particles, circuit motifs, and decorative data UI;
- avoid generic inspirational copy and over-polished synthetic imagery.

## Revision diagnosis

- **Feels like a PPT:** too many static cards, centered copy, and evenly timed dissolves. Replace with source-led cuts, kinetic type, and asymmetrical compositions.
- **Looks blurry:** the source is being enlarged too far, recompressed repeatedly, or exported below target quality. Use the original file, reduce display size, and render once from the master timeline.
- **Has black bars:** aspect ratios are mixed without a layout system. Reframe or use a consistent designed container.
- **Feels repetitive:** the same identity image or result clip is filling multiple story beats. Assign each asset one narrative job.
- **Voiceover feels flat:** it begins with background information instead of the change. Move the surprising behavior or result to the first sentence.
- **Too much text:** narration, captions, and title cards repeat the same sentence. Give each channel a different job.
